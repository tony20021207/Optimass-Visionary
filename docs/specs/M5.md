# M5: Kinematics

- Lane: L3
- Location: `packages/kinematics`
- Contracts: `@optimass/types`

## Inputs → outputs
`PoseSequence` → `KinematicAnalysis { series, reps: RepSegment[] }`

## Responsibilities
- Joint and segment angles, angular velocity.
- Rep segmentation into eccentric / bottom / concentric / lockout.
- Tempo, ROM achieved per rep, left/right symmetry, wrist bar-path proxy.
- Metric names are stable strings (e.g. `left_knee_flexion_deg`) that M6a rules reference.

## Out of scope
- Judging whether a value is an error (M6a).

## Acceptance tests
- `squatSagittal2Reps` fixture yields 2 reps; `standingFrontalStatic` yields 0.
- Knee flexion peaks at the bottom of each rep.
- Every RepSegment parses with `RepSegment`.
- Pure functions: no DOM or MediaPipe imports.

Done when `pnpm test`, `pnpm lint` and `pnpm typecheck` pass.
