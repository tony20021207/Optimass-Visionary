# M3: Program builder

- Lane: L1
- Location: `packages/program-builder`
- Contracts: `@optimass/types`

## Inputs → outputs
`ProgramRequest`, exercise library, `ExerciseRating[]` → `Program`

## Responsibilities
- Weekly sets per muscle from volume landmarks (MEV/MAV/MRV-style) in content/.
- Split generation for 1–7 days per week.
- Exercise selection by rating, respecting exclusions and fatigue cost.
- Progression model and deload week.

## Out of scope
- UI (M7). Persistence (M9).

## Acceptance tests
- Output parses with `Program`.
- Priority muscles get more weekly sets than non-priority ones.
- Excluded exercises never appear.
- Same input gives the same program (deterministic).
