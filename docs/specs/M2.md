# M2: Exercise rating engine

- Lane: L1
- Location: `packages/exercise-rating`
- Contracts: `@optimass/types`

## Inputs → outputs
`Exercise`, target muscle id, `RatingRubric` (content/rating), `AnatomyKb` → `ExerciseRating`

## Responsibilities
- Load the rubric: criteria ids, weights and per-criterion scoring tables.
- Score each criterion 0..1 and compute a weighted total 0..100.
- Criteria planned: resistance profile vs. length-tension (stretch loading), stability/external support, effective ROM, stimulus-to-fatigue, axial/systemic fatigue cost.

## Out of scope
- Choosing weights or scoring tables in code.
- Program construction (M3).

## Acceptance tests
- Changing a weight in content changes the total without code changes.
- Total equals the weighted mean of criteria × 100 (unit test).
- Rating records the rubric version.
- Rejects a target muscle the exercise doesn't train.
