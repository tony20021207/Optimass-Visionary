# M1: Anatomy knowledge base

- Lane: L1
- Location: `packages/anatomy-kb`
- Contracts: `@optimass/types`

## Inputs → outputs
`content/anatomy/*.yaml` (Tony) → `AnatomyKb { muscles: Muscle[]; joints: Joint[] }`

## Responsibilities
- Load and Zod-validate muscles and joints from content/anatomy.
- `musclesActingOn(kb, joint, action)` and `romNorm(kb, joint, action)` queries.
- Report referential errors (unknown joint, duplicate id) with file and entry.

## Out of scope
- Inventing anatomy data. Ship with a tiny placeholder dataset only for tests.
- Exercise rating (M2).

## Acceptance tests
- Loading a valid fixture dataset returns typed muscles and joints.
- Invalid content fails with a message naming the file and id.
- `musclesActingOn('knee','extension')` returns every muscle whose actions include it.
- `romNorm` returns undefined when content has no norm.
