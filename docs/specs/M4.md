# M4: Pose capture

- Lane: L3
- Location: `packages/pose-capture`
- Contracts: `@optimass/types`

## Inputs → outputs
Camera `MediaStream` or uploaded `HTMLVideoElement` → stream of `PoseFrame`, final `PoseSequence`

## Responsibilities
- Run MediaPipe Pose Landmarker (`@mediapipe/tasks-vision`, VIDEO mode) in a Web Worker.
- Smoothing (e.g. One Euro filter) and visibility gating.
- Record decisions (model file hosting, worker setup) in the package CLAUDE.md.

## Out of scope
- Angles, reps or any domain logic (M5+).
- UI (M8).

## Acceptance tests
- Smoothing reduces jitter on a noisy synthetic sequence (unit test, no camera).
- Every emitted frame parses with `PoseFrame`.
- Landmarks below minVisibility are flagged, not silently used.
- `stop()` returns a `PoseSequence` with ordered timestamps.

Done when `pnpm test`, `pnpm lint` and `pnpm typecheck` pass.
